# 🏆 WayHax - Единый портал образовательных конкурсов

Современная веб-платформа для организации и участия в образовательных конкурсах, олимпиадах, хакатонах и творческих соревнованиях. Платформа разработана с особым вниманием к **доступности** и **инклюзивности**, предоставляя уникальные инструменты для слабовидящих и незрячих студентов.

## 🌟 Ключевые особенности

### ♿ Система доступности (Accessibility First)

**Уникальная фича проекта** - комплексная система поддержки слабовидящих и незрячих пользователей:

- **🔤 Переводчик на шрифт Брайля**
  - Отдельная страница с переводом текста в шрифт Брайля
  - Увеличение размера шрифта для удобного чтения
  - Текст-в-речь (Text-to-Speech) для озвучивания контента
  - Копирование переведенного текста в буфер обмена

- **🎨 Настройки оформления**
  - **5 цветовых тем**: синяя, фиолетовая, зеленая, оранжевая, бирюзовая
  - **Увеличение шрифта** (глобальное масштабирование всей страницы)
  - **Высокий контраст** для улучшения читаемости
  - **Сброс настроек** к значениям по умолчанию
  - Плавные анимации и переходы

- **🌐 Многоязычность**
  - Переключение между русским и английским языками
  - Интерфейс полностью локализован

### 🎓 Управление конкурсами

- **Создание конкурсов** с полной информацией:
  - Название, описание, полное описание
  - Тип конкурса (олимпиада, творческий, спортивный, хакатон)
  - Кастомные хэштеги с эмодзи (#хакатон 🚀)
  - Загрузка изображения конкурса
  - Прикрепление файлов (PDF, DOC, DOCX и др.)
  - Документы и задания в текстовом формате
  - Даты начала и окончания
  - Лимит участников

- **Управление заявками**:
  - Просмотр всех заявок на конкурс
  - Установка оценок участникам
  - Изменение статуса заявок (ожидание, одобрено, отклонено, победитель)
  - Фильтрация и поиск

### 🏅 Система сертификатов

**Инновационная система автоматической генерации сертификатов:**

- **🤖 Автоматическая генерация**
  - Автоматическое определение победителей по максимальным оценкам
  - Генерация красивых сертификатов для топ-N участников
  - Использование данных участника (имя, команда, логин)
  - Три стиля шаблонов: элегантный, современный, классический

- **🎨 Конструктор сертификатов**
  - Ручное создание персонализированных сертификатов
  - Выбор участника из списка заявок
  - Редактирование всех полей (имя, команда, достижение)
  - Добавление кастомного текста
  - Выбор стиля шаблона
  - Предпросмотр в реальном времени
  - Сохранение в формате PNG

### 📎 Работа с файлами

- **Загрузка файлов к конкурсам**:
  - Поддержка PDF, DOC, DOCX, TXT, XLS, XLSX, PPT, PPTX, ZIP, RAR
  - Ограничение размера до 50MB на файл
  - Множественная загрузка
  - Просмотр и скачивание файлов участниками
  - Красивое отображение с иконками и размерами

### 🏷️ Кастомные хэштеги

- Организаторы могут добавлять собственные хэштеги к конкурсам
- Автоматическое форматирование с символом `#`
- Эмодзи для визуального выделения
- Отображение на карточках конкурсов в каталоге

## 🛠 Технологический стек

### Backend
- **FastAPI** - современный асинхронный веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **PostgreSQL** - реляционная база данных
- **Pydantic** - валидация данных и сериализация
- **Passlib (bcrypt)** - безопасное хеширование паролей
- **Uvicorn** - ASGI сервер

### Frontend
- **React 19** - библиотека для построения UI
- **TypeScript** - типизированный JavaScript
- **React Router DOM** - маршрутизация
- **Vite** - быстрый сборщик и dev-сервер
- **Tailwind CSS** - утилитарный CSS фреймворк
- **Lucide React** - современные иконки
- **Canvas API** - генерация изображений сертификатов
- **Web Speech API** - синтез речи для доступности

## 🚀 Быстрый старт

### Требования

- Python 3.9+
- Node.js 18+
- PostgreSQL 12+
- npm или yarn

### Установка Backend

```bash
cd backend
pip install -r requirements.txt
```

Настройте базу данных в `backend/app/database.py`:

```python
DATABASE_URL = "postgresql://user:password@localhost/dbname"
```

Запуск сервера:

```bash
cd backend
python run.py
# или
uvicorn app.main:app --reload --port 8000
```

API будет доступно по адресу: `http://localhost:8000`

### Установка Frontend

```bash
cd frontend
npm install
```

Запуск dev-сервера:

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Сборка для production

```bash
cd frontend
npm run build
```

## 🔌 API Эндпоинты

### Аутентификация (`/auth`)
- `POST /auth/register` - Регистрация
- `POST /auth/login` - Вход
- `GET /auth/me` - Текущий пользователь

### Конкурсы (`/contests`)
- `POST /contests` - Создать конкурс
- `GET /contests` - Список конкурсов (с фильтрами)
- `GET /contests/{id}` - Детали конкурса
- `PUT /contests/{id}` - Обновить конкурс
- `DELETE /contests/{id}` - Удалить конкурс
- `POST /contests/{id}/image` - Загрузить изображение
- `POST /contests/{id}/files` - Загрузить файл
- `POST /contests/{id}/publish-results` - Опубликовать результаты

### Заявки (`/applications`)
- `POST /applications` - Подать заявку
- `GET /applications/user/{user_id}` - Заявки пользователя
- `GET /applications/contest/{contest_id}` - Заявки на конкурс
- `PUT /applications/{id}` - Обновить заявку (статус, оценка)

### Сертификаты (`/certificates`)
- `POST /certificates/auto-generate` - Автоматическая генерация
- `POST /certificates` - Создать сертификат вручную
- `GET /certificates/contest/{contest_id}` - Сертификаты конкурса
- `GET /certificates/{id}` - Детали сертификата
- `POST /certificates/{id}/save-image` - Сохранить изображение

## 📊 База данных

### Основные таблицы:

- **auth** - Аутентификация (логин, email, пароль, роль)
- **users** - Профили пользователей (имя, телефон, аватар, образование)

## 🌟 Уникальные фичи проекта

### 1. Система доступности
Проект выделяется комплексной системой поддержки слабовидящих и незрячих пользователей, что делает его уникальным среди образовательных платформ.

### 5. Кастомные хэштеги
